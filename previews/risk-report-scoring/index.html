产品风控结论

页面 PRD

一、展示位置与来源

“风控评分”位于基础信息之后、产品风控结论之前。页面读取本单当前报告修订对应的评分结果。

二、规则与判断条件

评分标题旁显示本单命中的策略名称。判断条件、订单情况和是否命中各占一列。多条件规则逐条对齐，且或关系显示在条件之间，规则名称和计入分各显示一次。复合规则带标签，并逐项标明所属产品。

三、计入分与总分

分值归整条评分规则。取最高未计入的规则显示 0 分。产品封顶差额单列。产品得分加复合附加分为综合总分。

四、结果状态

同一张表展示命中、未命中及未参与的规则，命中的规则排在前面。未命中计 0 分，未参与显示「—」及原因。等待取数时显示暂定得分，暂无评分时显示空状态。

五、评审操作

顶部切换演示场景。可拖动分隔条或按方向键调整宽度，双击或按 0 恢复默认值。右上角可收起和展开说明。
